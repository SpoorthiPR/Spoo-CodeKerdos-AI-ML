Q1. What is a List?
A List in Python is an ordered, mutable (changeable) collection of items enclosed in square brackets []. It allows duplicate elements and can store heterogeneous data types (integers, strings, floats, etc.).

Q2. What is a Tuple?
A Tuple in Python is an ordered, immutable (unchangeable) collection of items enclosed in parentheses (). Like lists, tuples allow duplicate values and mixed data types, but their elements cannot be modified after creation.

Q3. What is the difference between List and Tuple?
- Mutability: List is mutable (can add, update, or delete items); Tuple is immutable (cannot be modified once created).
- Syntax: List uses square brackets [1, 2, 3]; Tuple uses parentheses (1, 2, 3).
- Performance: List is slightly slower due to dynamic resizing; Tuple is faster and uses less memory.
- Use Case: List is used for dynamic collections that change over time; Tuple is used for fixed data or dictionary keys.

Q20. What's The Difference Between The Python append() and extend() Methods?
- append(x): Adds x as a single element at the end of the list (increases length by 1). Example: [1, 2].append([3, 4]) -> [1, 2, [3, 4]]
- extend(iterable): Unpacks and appends each element of the iterable individually. Example: [1, 2].extend([3, 4]) -> [1, 2, 3, 4]

Q27. How to sort a list in ascending and descending order without using the sort function?

# Bubble sort for Ascending
asc = nums[:]
for i in range(len(asc)):
    for j in range(0, len(asc) - i - 1):
        if asc[j] > asc[j + 1]:
            asc[j], asc[j + 1] = asc[j + 1], asc[j]
desc = asc[::-1]
print("Ascending:", asc)
print("Descending:", desc)

Output:

Q30. What is the difference between del and clear?
- del: A statement that deletes a specific slice/index or removes the entire variable reference from memory (del lst removes lst completely, causing a NameError if accessed).
- clear(): A built-in list method that empties all items inside the list (lst.clear() leaves an empty list [] intact in memory).

Q31. What is the difference between remove and pop?
- remove(val): Deletes the first matching occurrence by value (raises ValueError if missing) and returns None.
- pop(idx): Deletes the element at the given index (defaults to last item if omitted) and returns the removed element.

Q32. What is the difference between indexing and Slicing?
- Purpose: Indexing (lst[i]) accesses a single element at a specific position; Slicing (lst[start:stop:step]) extracts a contiguous or stepped range of elements.
- Return Type: Indexing returns the single element itself; Slicing returns a new list/tuple containing the selected items.
- Out-of-Range: Indexing raises IndexError if index is out of bounds; Slicing safely truncates without raising an error.

Q33. What is the difference between sort and sorted?
- Mutation: list.sort() sorts the list in-place (modifies the original list); sorted(iterable) leaves the original iterable unchanged.
- Return Value: list.sort() returns None; sorted(iterable) returns a brand-new sorted list.
- Applicability: list.sort() works exclusively on lists; sorted(iterable) works on any iterable (lists, tuples, sets, strings).

Q34. What is the difference between reverse and reversed function?
- Mutation: list.reverse() reverses the list in-place; reversed(seq) does not modify the original sequence.
- Return Value: list.reverse() returns None; reversed(seq) returns a lazy reverse iterator object.
- Applicability: list.reverse() works only on lists; reversed(seq) works on any sequence (lists, tuples, strings, ranges).

Q35. What is the difference between copy and deep copy?
- Shallow Copy (copy.copy()): Creates a new outer container object and copies references to nested mutable objects (changes inside nested items affect both).
- Deep Copy (copy.deepcopy()): Creates a new outer container object and recursively duplicates all nested objects so both copies are 100% independent.
